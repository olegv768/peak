# Пик

Пик сам находит лучшие моменты стрима и режет их в вертикальные шорты для TikTok, YouTube Shorts и Reels.

Момент ищется по шести сигналам сразу:

- **стример** — голос (крик, смех, смена тона), эмоции на камере, слова;
- **зрители** — всплеск в чате, донаты, клипы, которые сделали сами зрители.

Один сигнал часто врёт: стример крикнул просто так, чат заспамил бот. Там, где совпало несколько сигналов, — настоящий момент.

## Что есть в демо-версии

| Часть | Как работает |
|---|---|
| Ссылка на стрим | Заглушка: принимает ссылку Twitch, VK Play Live, VK Видео, YouTube, Kick или Rutube и показывает результат обработки на примере стрима |
| Примеры стримов (Хоррор, Общение, Шутер) | Вымышленные стримы: обработка по шагам, шкала шести сигналов, готовые шорты с субтитрами и репликами чата |
| «Проверьте на своём стриме» | **Работает по-настоящему** в браузере: загружаете чат записи (JSON или TXT из TwitchDownloader), Пик находит всплески и режет моменты. С загруженной записью каждый момент играет вертикально |
| Скачать / опубликовать | Заглушки: показывают, что функция появится в полной версии |

Файлы пользователя никуда не отправляются: всё считается в браузере.

Для проверки без своего файла есть кнопка «Проверить на примере чата» и файл [`assets/sample-chat.txt`](assets/sample-chat.txt).

## Запуск

Сайт статический, сборка не нужна.

- Открыть `index.html` в браузере, или
- запустить локальный сервер:

  ```bash
  python -m http.server 5173
  ```

  и открыть http://localhost:5173

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**. Через минуту сайт будет по адресу `https://<логин>.github.io/peak/`.

## Структура

```
index.html          страница
assets/styles.css   стили
assets/data.js      сигналы, типы моментов, примеры стримов
assets/analyzer.js  настоящий поиск моментов по чату
assets/app.js       интерфейс: обработка, шкала сигналов, шорты, окно момента
assets/sample-chat.txt  пример чата 3-часового стрима
```
