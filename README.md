# Пик

Пик сам находит лучшие моменты стрима и режет их в вертикальные шорты для TikTok, YouTube Shorts и Reels.

Момент ищется по шести сигналам сразу:

- **стример** — голос (крик, смех, смена тона), эмоции на камере, слова;
- **зрители** — всплеск в чате, донаты, клипы, которые сделали сами зрители.

Один сигнал часто врёт: стример крикнул просто так, чат заспамил бот. Там, где совпало несколько сигналов, — настоящий момент.

## Что работает сейчас

| Часть | Как работает |
|---|---|
| Ссылка на стрим | Принимает ссылку Twitch, VK Play Live, VK Видео, YouTube, Kick или Rutube; пока показывает результат на примере стрима |
| Примеры стримов (Хоррор, Общение, Шутер) | Обработка по шагам, шкала шести сигналов, готовые шорты с субтитрами и репликами чата |
| «Проверьте на своём стриме» | **Настоящий анализ** в браузере: чат записи (JSON или TXT из TwitchDownloader) → всплески → моменты. С загруженной записью каждый момент играет вертикально |
| Скачать MP4 | Скоро |

Файлы пользователя никуда не отправляются: всё считается в браузере. Пример чата для проверки — [`public/sample-chat.txt`](public/sample-chat.txt).

## Стек

Vite, React, TypeScript, Tailwind CSS, three.js (3D-сцена на первом экране).

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # проверка типов и сборка в dist/
npm run preview    # посмотреть собранный сайт
```

## Публикация

Сайт публикуется на Vercel: каждый пуш в `main` собирается и выкладывается автоматически.

## Структура

```
src/App.tsx                    страница и запуск обработки
src/components/Hero.tsx        первый экран: ссылка, примеры, телефон с шортом
src/components/RunSection.tsx  обработка по шагам и готовые шорты
src/components/Timeline.tsx    шкала шести сигналов
src/components/ShortCard.tsx   вертикальный шорт: субтитры, чат, видео
src/components/ShortModal.tsx  окно момента
src/components/How.tsx         как это работает
src/components/OwnStream.tsx   свой стрим: загрузка чата и записи
src/lib/analyzer.ts            поиск моментов по чату
src/lib/lanes.ts               дорожки сигналов для шкалы
src/data/samples.ts            сигналы, типы моментов, примеры стримов
```
